# Ценовна површина Србије

Тродимензионални приказ кретања цене стана по m² на мрежи над Србијом,
месечно од 01/2019 до 12/2026. Један самосталан HTML фајл — отвара се
двокликом, не тражи ни налог, ни сервер, ни инсталацију.

> ### СИНТЕТИЧКИ ПОДАЦИ
>
> Бројеви у овом репозиторијуму су **измишљени**. Прави их генератор са
> фиксним семеном да би се видело како приказ ради и изгледа. Не смеју се
> употребити за процену вредности, поређење подручја, ни као илустрација уз
> тврдњу о стварном стању тржишта. Место где се прикључује стварни извод из
> РГЗ-а описано је ниже.

---

## Шта је овде

```
generator/     генератор синтетичких цена + CLI који пише податке
prototip/      приказ: шаблон, апликација, скрипта за склапање
dokumentacija/ писана објашњења
isporuka/      оно што се шаље даље — прави га build, не чува се у гиту
```

Лана од извора до фајла који се предаје:

```
generator.js ──→ generisi.js ──→ podaci_15km/ ──→ napravi-hex.js ──→ cenovna-povrsina-3d.html
                                 tacke.csv          --podaci
                                 cene.bin
                                 meta.json
```

## Брзи старт

Потребан је Node (без иједне зависности из `npm install` — само `npm pack`
за deck.gl бандл).

```bash
node generator/generisi.js --korak 1.5 --izlaz generator/podaci_15km
```

Затим се, из `prototip/`, преузме deck.gl и склопи приказ:

```bash
npm pack deck.gl@9.3.10 && tar -xzf deck.gl-9.3.10.tgz
```

```bash
curl -LO https://unpkg.com/maplibre-gl@4.7.1/dist/maplibre-gl.js && curl -LO https://unpkg.com/maplibre-gl@4.7.1/dist/maplibre-gl.css
```

```bash
node napravi-hex.js --deck ./package/dist.min.js --maplibre ./maplibre-gl.js --maplibre-css ./maplibre-gl.css --podaci ../generator/podaci_15km
```

Излаз је `isporuka/cenovna-povrsina-3d.html` — око 5,3 MB, отвара се
двокликом. Верзије су намерно закуцане: без броја верзије исте улазне
датотеке кроз пола године дају другачији резултат.

## Како приказ ради

Мрежа је **шестоугаона**, а приказ црта једну ћелију по тачки, deck.gl-овим
`ColumnLayer`-ом. Боја носи цену, висина носи индекс кретања (01/2019 = 1).
Палета, материјал, светло и угао камере преузети су из званичног deck.gl
примера [`examples/website/3d-heatmap`](https://github.com/visgl/deck.gl/tree/9.3-release/examples/website/3d-heatmap).

Оно што приказ **не** ради јесте груписање: подаци стижу већ подељени по
ћелијама, па би слање у агрегациони слој значило делити већ подељено.
Разлог и мерење су у [`prototip/README.md`](prototip/README.md).

| управљач | шта мења |
|---|---|
| Обухват података | колики део мреже се црта — задржава p % ћелија ближих градовима |
| Горњи перцентил | склања најскупље ћелије са приказа |
| Попуњеност | колико од ћелије заузима стуб |
| Висина | колико се стубови издижу |
| Боја носи | цену по m², или одступање од просека месеца |

Клик на ћелију исцрта њено кретање кроз свих 96 месеци. Подешавања стају у
адресу, па се готов поглед пошаље линком:

```
cenovna-povrsina-3d.html?obuhvat=10&percentil=95&mesec=2024-06&boja=odstupanje
```

## Где се прикључује стварни извод из РГЗ-а

`napravi-hex.js --podaci` чита фолдер са три фајла, у формату који
`generisi.js` већ пише:

| фајл | шта носи |
|---|---|
| `tacke.csv` | `id,lon,lat,…` — читају се прве три колоне |
| `cene.bin` | `uint16` LE, месец-major: `[месец0: све тачке][месец1: …]` |
| `meta.json` | `broj_tacaka`, `broj_meseci`, `meseci[]`, `celija`, `napomena` |

Извод из РГЗ-а се **не чита у овом коду**. Доведе се у ова три фајла једном
скриптом за конверзију — која тек треба да се напише — а цео остатак ланца
остаје непромењен.

Колико тога стане у један фајл (измерено, кроз цео ланац):

| корак | тачака | сирово | делта+gzip | укупан HTML |
|---|---|---|---|---|
| 3 km | 9.832 | 1,80 MB | 0,54 MB | 3,2 MB |
| 1,5 km | 39.303 | 7,20 MB | 2,13 MB | 5,3 MB |
| 0,5 km | ~353.600 | 64,8 MB | 17,7 MB | тражи сервер |

## Шта треба поправити пре стварне употребе

- **Граница није катастарски податак.** Долази из Natural Earth 1:10m
  (слојеви `SRB` и `KOS`), упрошћена на око 220 m. Одступа од званичне
  границе за око 0,15 % по површини — испод једне ћелије на кораку од 1,5 km,
  али недовољно за посао који се пореди са катастром. За то иде званична
  граница из ГеоСрбије.
- **Пројекција није званични CRS.** За поређење са катастарским подацима иде
  UTM 34N (EPSG:32634), односно EPSG:8682.
- **Мрежа је потпуно попуњена.** Свака ћелија унутар границе има цену — и
  шума, и језеро. Стварни подаци имају рупе. Клизач „обухват података" је
  замена за то док прави податак не стигне — његов проценат је удео исцртаних
  ћелија, не процена насељене површине.

Потпун списак ограничења је у [`generator/README.md`](generator/README.md).

## Лиценце

Код у овом репозиторијуму је рад РГЗ-а. Уграђене библиотеке носе своје
лиценце — `napravi-hex.js` уз сваку изградњу пише `LICENSES.txt` са
напоменама (deck.gl MIT, maplibre-gl BSD-3-Clause). Тај фајл треба да путује
заједно са приказом.

Подлога карте није уграђена: стиже са CARTO сервиса и користи се под њиховим
условима, који траже да на карти остану видљиви потписи CARTO и
OpenStreetMap.
