# Прототипови приказа

Два прототипа, оба се отварају локално. Ниједан не тражи налог, сервис
ни спољну услугу.

## `hexagon-layer.html` — deck.gl HexagonLayer

Висина шестоугла носи индекс кретања у односу на јануар 2019, боја носи
цену по m². Палета, материјал, светло и угао камере преузети су из
званичног deck.gl примера `examples/website/3d-heatmap`.

Прави се у две варијанте:

| фајл | величина | тражи интернет |
|---|---|---|
| `hexagon-layer.html` | ~1,6 MB | не — deck.gl је уграђен у фајл |
| `hexagon-layer-cdn.html` | ~30 KB | да — deck.gl се повлачи са unpkg-а |

CDN варијанта је писана исто како deck.gl пише своје „scripting" примере,
па се најлакше пореди са примером на њиховом сајту и најлакше преноси у
њихову структуру пројекта. Уграђена варијанта ради без мреже.

### Прављење

```bash
npm pack deck.gl
```

```bash
tar -xzf deck.gl-*.tgz
```

```bash
node napravi-hex.js --deck ./package/dist.min.js
```

`npm pack` преузима само тарбол, без стабла зависности — траје неколико
секунди, док пуно `npm install deck.gl` овде није успело ни за десет минута.

Делови од којих се склапа:

| фајл | шта је |
|---|---|
| `hex-sablon.html` | HTML и CSS |
| `hex-app.js` | слојеви, клизачи, управљање погледом |
| `../generator/generator.js` | генератор, исти као за податке |
| `deck.gl/dist.min.js` | бандл, уграђује се или се повлачи са unpkg-а |

Скрипта успут издваја напомене о лиценцама уграђених библиотека у
`deck.gl-LICENSES.txt`, како то ради и webpack.

### Пренос у deck.gl структуру

Ако треба да ради унутар њиховог пројекта уместо самостално, из
`hex-app.js` се узимају `PALETA`, `MATERIJAL`, подешавања `HexagonLayer`-а
и `LightingEffect`, а `pripremi()` се замени учитавањем стварних података.
Остало је исто као у њиховом примеру.

## `cenovna-povrsina.html`

Поређење шест начина приказа исте просторно-временске појаве: ниво цена,
индекс, мапа промене, мале карте по годинама, бивариантни ниво × раст и 3Д.
Црта се на canvas-у, без иједне спољне библиотеке — фајл се отвара директно
двокликом.

## Отварање преко локалног сервера

Двоклик је довољан за оба фајла. Ако вам ипак треба сервер — рецимо да
проверите понашање без `file://` ограничења:

```bash
python -m http.server 8777 --directory prototip
```

Затим отворити `http://localhost:8777/hexagon-layer.html`.

## Две ствари на које пазити

**Не користити `requestAnimationFrame` за покретање.** У картици која није
видљива он се не извршава, па се страница никад не иницијализује. Оба
прототипа зато користе `setTimeout`.

**`initialViewState` се чита само при покретању.** Ако поглед треба мењати
дугметом, стање мора да се држи споља и прослеђује као `viewState`.
